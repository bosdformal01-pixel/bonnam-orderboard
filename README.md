# 복남이 샌드 주문판

카운터 포스와 샐러드바·샌드위치바 태블릿에서 같이 쓰는 주문판이에요.

- 주소: https://bosdformal01-pixel.github.io/bonnam-orderboard/
  - 카운터: `#counter`, 샐러드바: `#salad`, 샌드위치바: `#sandwich`
- 주문은 구글 Firebase(프로젝트 `bosd-project`)에 저장돼요. `firestore.rules`에 적힌 가게 구글 계정으로 로그인한 기기만 주문을 읽고 쓸 수 있어요. 이 저장소에는 주문 내용이 들어 있지 않아요.
- 전표는 카운터 포스의 영수증 프린터(COM4, 9600)로 바로 나가요. 처음 한 번 "🔌 영수증 프린터 연결하기"를 눌러 COM4를 골라 주세요. (크롬에서만 돼요)
- 단체 주문은 카운터의 "📅 예약 주문"으로 날짜·시간을 정해 미리 넣어 둬요. 그날이 되면 카운터와 태블릿에 주문으로 들어가 있고, 전날 오전 11시·저녁 7시 반에 "내일 예약 주문을 확인하세요!" 알림이 떠요 (주문판이 켜져 있을 때만).
- "📋 마감 요약 · 달력"에서 달력으로 날짜별 매출을 보고, 날짜를 누르면 그날 내용을 자세히 봐요.
- "🛵 배달앱 전표 받기" (카운터): 배민·요기요·쿠팡이츠·네이버 주문 프로그램은 전표를 가상 포트 COM10 으로 보내고(com0com 으로 COM10↔COM11 연결, 쿠팡이츠는 COM10 으로 가는 윈도우 프린터 '쿠팡시험'), 카운터 주문판이 COM11 에서 받아 COM4 프린터로 넘기면서 (COM4 는 보낼 때만 잠깐 열어요. 네이버 주문 프로그램은 COM10 이 목록에 없어 COM4 그대로 써요) 주문판에 배달 주문으로 넣어요. 테스트 출력은 프린터로만 넘기고 주문판엔 안 넣어요. 손님 주소·전화번호·전표 글자는 다음 날 지워요.
  - **카운터 크롬 주문판이 꺼져 있으면 배달 전표가 안 나와요.** 급하면 배달앱 프린터 설정을 COM4 로 돌리면 원래대로 나와요.
